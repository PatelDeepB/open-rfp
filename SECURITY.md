# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of OpenRFP seriously. If you discover a security vulnerability,
please do not create a public issue.

Instead, please send an email with the details, steps to reproduce, and impact to:
`deep.patel@example.com` (or create a private GitHub Security Advisory).

We will respond promptly and coordinate a patch and responsible disclosure timeline.
