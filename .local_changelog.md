# OpenRFP Changelog & Change Tracker

All notable changes and architectural decisions for this project will be documented in this file.

## [0.1.0] - 2026-11-02

### Production Hardening & Multi-Format Ingestion
- Multi-format RFP ingestion: Added native document shredders for PDF (`pypdf`), Word DOCX (`docx`), and CSV spreadsheets (`csv`) in `RfpParser`.
- Unified LLM Provider: Added `openrfp.core.llm.LlmClient` supporting OpenAI, Anthropic, Gemini, or deterministic citation grounding when no API key is supplied.
- Upgraded Web UI Dashboard:
  - Added HTML5 file drag/drop document loader.
  - Added instant 1-click export download buttons for Markdown, CSV, and HTML.
  - Added interactive SME Action Tasks tab to inspect and audit departmental routing.
- Expanded test suite:
  - Added DOCX and CSV parser unit tests.
  - Added `tests/test_llm.py` for LLM provider fallbacks.
  - Added `tests/test_storage.py` covering persistent JSON operations and edge cases.
  - Added full format export and error handling tests in `tests/test_api.py`.
  - Reached 42 passing tests with 91%+ overall test coverage.

### Initial Architecture & Core Implementation
- Project initialized with pyproject.toml, standard open-source governance (LICENSE, CODE_OF_CONDUCT, CONTRIBUTING, SECURITY).
- Created domain data models using Pydantic v2:
  - `RfpDocument`, `RfpSection`, `ComplianceRequirement`
  - `KnowledgeItem`, `KnowledgeSearchQuery`, `SearchResult`
  - `DraftAnswer`, `ConfidenceLevel`, `ProposalSummary`
  - `SmeTask`, `GapReport`, `ExportFormat`
- Implemented core engines:
  - `openrfp.core.parser`: Document shredder for Markdown, text, and structured RFPs. Extracts compliance matrix with category and priority classification.
  - `openrfp.core.retriever`: Enterprise knowledge hybrid retrieval with lexical and semantic scoring, provenance citation, and fallback indexing.
  - `openrfp.core.drafter`: Context-aware proposal drafting with traffic light confidence scoring (Green/Amber/Red) and buyer terminology alignment.
  - `openrfp.core.gap_analyzer`: Automated gap identification, risk scoring, and departmental SME routing.
  - `openrfp.core.exporter`: Multi-format compilation (Markdown proposal, Compliance Matrix CSV/HTML/JSON, Executive Brief).
- Implemented storage layer:
  - `openrfp.storage`: Local persistent JSON/file storage for RFPs, compliance matrices, and knowledge base items.
- Built interface layer:
  - `openrfp.api.server` & `openrfp.api.routes`: Full FastAPI v1 endpoints with OpenAPI documentation and `/health` probe.
  - `openrfp.web.ui`: Self-contained modern interactive web UI with real-time requirement filtering, confidence metrics, and one-click export.
  - `openrfp.cli`: Rich Typer CLI with terminal tables, progress indicators, and commands for shredding, matching, drafting, exporting, and serving.
- Sample data & comprehensive test suite with 100% AAA test structure.
